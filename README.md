# Loyola Hockey Matches (v2)

Partidos, clasificaciones y directo de los equipos de hockey patines del Loyola Indautxu. PWA instalable (iPhone) y app Android con Capacitor.

Stack: React 19, TypeScript, Vite, Ionic React, TanStack Query, i18next (es/eu), Vitest, Playwright.

## Empezar

```bash
npm install
npm start        # http://localhost:5173
npm test
npm run e2e
```
