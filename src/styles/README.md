# styles

Tokens CSS (custom properties) y tema claro/oscuro. Los colores por modo se definen bajo `body[data-theme]`, no en `:root`.

- `tema.css`: paleta de Ionic y tokens de la app (`--app-barra-superior`, `--app-barra-inferior`…) por tema.
- `tokens.css`: constantes de marca que no cambian con el tema.
